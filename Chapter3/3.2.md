## yield 是什么
* 一个词来说就是实现了一个 **惰性迭代** ,返回的类型是一个可迭代对象
```py
    def data_iter(batch_size, features, labels):
        num_examples = len(features)
        indices = list(range(num_examples))
        # 这些样本是随机读取的，没有特定的顺序
        random.shuffle(indices)
        for i in range(0, num_examples, batch_size):
            batch_indices = torch.tensor(
                indices[i: min(i + batch_size, num_examples)])
            yield features[batch_indices], labels[batch_indices]
```
* 对于这个代码来说,我可以直接把这个函数当作为一个迭代器来参加到代码里,也可以用`next()`来显示的迭代
```py
for X, y in data_iter(batch_size, features, labels):
    print(X, y)
# 下面这种也是对的 
data_gen = data_iter(batch_size, features, labels)

X, y = next(data_gen)
print(X, y)

X, y = next(data_gen)
print(X, y)
```
## 为什么tensor的索引也可以是个tensor?
* 这是所谓的高级索引
  * 比如说 
```py
features = torch.tensor([
    [1, 2],
    [3, 4],
    [5, 6],
    [7, 8],
])

labels = torch.tensor([10, 20, 30, 40])

batch_indices = torch.tensor([2, 0])
features[batch_indices]
# 结果上是:
# tensor([
#     [5, 6],
#     [1, 2]
# ])
```
## 什么是with句式?
```py
with torch.no_grad():
        train_l =loss(net(features,w,b),labels)
```

## 练习的内容好多!
1. 算法依然有效,因为这里用这个东西是能算出来非零loss的 ,也就是说是能进行正常的梯度下降的
2. 没问题,就标标准准的做就行了
3. 虽然说得到的光谱图是离散的,但是我们要可微的函数可以不是,所以说原则上这个也是可以的
4. 求高阶导数的最大问题应该是Hessian矩阵求出来是个$O(N^2)$的时空复杂度,这在大部分时候都是无法接受的,所以说,我们采用的方法是: **Hessian-vector product**
    * 具体的说,就是我们其实不需要真的求出来$H$,我们真的要的是$Hv$,可以知道
    $$
    g = \frac{dL}{d\theta}
    $$

    $$
    Hv = \frac{d g^T v}{d\theta}
    = \frac{d g^T}{d\theta} v + g^T \frac{dv}{d\theta}
    = \frac{d g^T}{d\theta} v
    $$

    * 也就是说,我们其实可以直接对loss函数求梯度,然后算一个对v的乘积,最后对着这个的结果再算一次梯度
    * 可以认识到,这个的算法就是$O(N)$的了
5. 因为在数据处理的时候就有了y.shape(-1,1) ,也就是说这个y不是一个一维的tensor,所以说和linreg跑出来的结果其实是一样的
6. 这个拟合的速度好快,一下子loss就到了很小的位置了

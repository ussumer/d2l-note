# 成为api调用虾的路
## 写作业
1. 题目的意思是,如果用`nn.MSELoss(reduction='sum)`替换这里的默认的Loss(mean),应该怎么改动学习率?
   1. 这里相当于就是给loss乘上了个batch_size
   2. 自然的,我的梯度就会变为原来的十倍,
   3. 也就是说,我应该学习率直接除以一个batch_size,效果就是变为原来梯度下降的值了
2. 直接换着用就是了:
   ```py
   nn.MSELoss()        # 均方误差，回归常用
   nn.L1Loss()         # 平均绝对误差
   nn.HuberLoss()      # Huber 损失，回归，对异常值更稳
   nn.CrossEntropyLoss() # 多分类常用
   nn.BCELoss()        # 二分类概率损失
   ```
3. 直接对着weight和bias俩个参数对着print就好了:
```py
    print("weight 梯度:", net[0].weight.grad)
    print("bias 梯度:", net[0].bias.grad)
```

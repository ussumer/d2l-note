# 记录一下一些需要注意的东西?
## pytorch的concatenate操作:
* `torch.cat((X, Y), dim=0)`
* 这dim是谁就是哪个维度增加,下面是例子:
> X.shape =(2,3,4)
> Y.shape = (2, 3, 4)
> 2 个矩阵，每个矩阵是 3 行 4 列
> 
> dim=0：第几个矩阵
> dim=1：矩阵里的第几行
> dim=2：矩阵里的第几列
## 广播机制?
* 从后往前对齐 shape:
> A.shape = (2, 3, 4)
> B.shape = (3, 4)
> 从后往前对齐： 
> A: 2  3  4
> B:    3  4
> B 缺了最前面的维度，补成：
> B: 1  3  4
> 然后第 0 维从 1 扩展到 2：
> B: 2  3  4
* 两个维度能广播，需要满足：`两个维度相等，或者其中一个是 1`
## 内存节省
```py
Z = torch.zeros_like(Y)
Z[:] = X + Y
# 如果后续没有重复利用X
# 可以X[:] = X + Y或X += Y
before = id(X)
X += Y
id(X) == before # 结果为True
```

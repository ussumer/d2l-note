# 自动求导
## x.requires_grad_(True)是?
简单来说,就是告诉Pytorch:
> 从现在开始，请跟踪这个张量参与的运算，之后可以对它求梯度。
他不会立即创建梯度值,所以说一开始会是NAN
调用了`y.backward()`就会开始反向传播了,(沿着计算图)算出来一个梯度存在了 x.grad里面
## 上文说的是对于一个标量来说的求grad,如果说y的结果是个vector呢?
* 对于$y=x*x$
  我们会使用y.sum().backward()
  这里是在说,我是对于所有的[y1,y2,y3,y4]先进行一个求和然后实现对标量的求grad
  这里的代码等价于`y.backward(torch.ones(len(x)))`
  更一般的说是`y.backward(v)`算的是:
  `v₀y₀ + v₁y₁ + v₂y₂ + ... 对 x 的梯度`

## 一个神秘的操作:分离计算
* 一句话说就是求$F_x$和$F_1$之间的区别
* 我们使用的方法是`u=y.detach()`
  这个方法的意思就是说用y里的数值,生成一个tensor,是一个不再参与自动求导的tensor,也就是说不会因为对x求导而影响求导结果
  这个u一般来说是和y共享着同一块的数据内存
  也就是说,重新赋值tensor y不会影响u
  > 比如说 `y=y+1`
  > 这里的行为是创建了一个新tensor y+1 然后让y指向y+1
  > 但是修改就是在原来的内存空间里改
  > 有点闹麻但是反正知道这件事情就行

## Python控制流中的梯度计算
* 什么意思呢?就是说对于一个tensor来说,就算是中间过了很多个python中的控制流,选择/循环了很多次,他一样是知道中间的过程的,从而直接进行backward的计算得到grad
```py
def f(a):
    b = a * 2
    while b.norm() < 1000:
        b = b * 2
    if b.sum() > 0:
        c = b
    else:
        c = 100 * b
    return c
a = torch.randn(size=(), requires_grad=True)
d = f(a)
d.backward()
# 就像是这样的,这里是能正确计算出d的grad的
```

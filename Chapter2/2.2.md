## 用插值法处理缺失值
```
   NumRooms Alley   Price
0       NaN  Pave  127500
1       2.0   NaN  106000
2       4.0   NaN  178100
3       NaN   NaN  140000
```
* 如果说用均值来填充 NumRooms这项
  ```py
    inputs, outputs = data.iloc[:, 0:2], data.iloc[:, 2]
    inputs = inputs.fillna(inputs.mean(numeric_only=True))
    print(inputs)

       NumRooms Alley
    0       3.0  Pave
    1       2.0   NaN
    2       4.0   NaN
    3       3.0   NaN
  ```
  就好了
* 对于`Alley`这种离散的,非数字的类型,我们可以用`get_dummies`来改成one-hot编码
    `inputs = pd.get_dummies(inputs, dummy_na=True)`
    这个`dummy_na=True`是在说认为nan也是一种类型
    ```py
       NumRooms  Alley_Pave  Alley_nan
    0       3.0        True      False
    1       2.0       False       True
    2       4.0       False       True
    3       3.0       False       True
    ```

## 课后:删除法处理缺失值
```py
missing_counts = data.isna().sum()
col_to_drop = missing_counts.idxmax()

data = data.drop(columns=[col_to_drop])
```
是这样的:
* data.isna()是判断每个位置是不是nan,然后返回一个0-1的tensor
* .sum() 这个函数默认是对axis=0求和,也就是说求和算一下每一个列nan的数量
* .idxmax()返回最大的值的那个列的列标
* 最后调用drop把那个列去掉 <- colums =[col_to_drop]的意思是对着axis=1 找到col_to_drop的那个标签,删掉有关
```py
   NumRooms Alley   Price
0       NaN  Pave  127500
1       2.0   NaN  106000
2       4.0   NaN  178100
3       NaN   NaN  140000
就直接转变为
   NumRooms   Price
0       NaN  127500
1       2.0  106000
2       4.0  178100
3       NaN  140000
```
* 一行可以说完:`data = data.drop(columns=[data.isna().sum().idxmax()])`
